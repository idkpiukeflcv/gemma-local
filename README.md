## Overview

Gemma is Google DeepMind's family of open-weight large language models designed for efficient local inference. The Gemma models — ranging from 2B to 27B parameters — are optimized for on-device use via llama.cpp and Ollama, and deliver strong performance across text generation, summarization, coding assistance, and multi-turn conversation.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Gemma** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multiple Sizes** | Available in 2B, 7B, 9B, and 27B parameter sizes for any hardware |
| **llama.cpp Compat** | Runs via llama.cpp for optimized CPU and GPU quantized inference |
| **Instruction Tuned** | Instruction-following variants optimized for chat and task completion |
| **Commercial Use** | Gemma terms permit commercial use and derivative model creation |
